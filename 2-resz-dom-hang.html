1. Mi az a DOM?

Amikor a böngésző betölt egy HTML-fájlt, felépít belőle egy fa-szerkezetet. Ezt hívjuk DOM-nak (Document Object Model, dokumentumobjektum-modell). Minden HTML-elem egy ága ennek a fának.

html
├── head
│   └── title
└── body
    ├── h1
    ├── p
    └── button

A JavaScript a DOM-on keresztül éri el az oldal elemeit. Ha megváltoztatod a fát, a képernyőn is változik minden, ami a fához tartozik.

Lényeg: a JavaScript nem a HTML-fájlt írja át, hanem az élő, a böngészőben lévő oldalt. A fájl változatlan marad, csak a képernyőn lévő kép változik.

2. Elemek kiválasztása

Ahhoz, hogy megváltoztasd egy elemet, először ki kell választanod. Három gyakori módja van:

// 1. azonosító szerint (id="cim")
const cim = document.querySelector("#cim");

// 2. osztály szerint (class="gomb")
const elsoGomb = document.querySelector(".gomb");

// 3. az összes ilyen elem, listaként
const osszesGomb = document.querySelectorAll(".gomb");
Jelölés: # az azonosítóra (id), . az osztályra (class) utal. A querySelector az első találatot adja, a querySelectorAll mindet.
Gyakori hiba: ha a querySelector null-t ad vissza, az azt jelenti, hogy a keresett elem nincs az oldalon. Ellenőrizd az id-t és a szóközöket, és a script elemet a HTML végére tedd, hogy a böngésző már mindent betöltsön.

3. Szöveg, tulajdonság és stílus módosítása

Egy kiválasztott elemnek több részét változtathatod meg:

const cim = document.querySelector("#cim");

cim.textContent = "Új cím";          // a szöveg
cim.setAttribute("title", "Súgó");   // egy tulajdonság, például a title
cim.style.color = "#e0457f";         // a stílus, a CSS-nek megfelelő névvel

Osztályok kezelése: classList

Egy elemre osztályt rakhatsz, és az osztály alapján a CSS más stílust adhat neki. A classList ezt kezeli:

const doboz = document.querySelector("#doboz");

doboz.classList.add("kiemelt");     // hozzáadja az osztályt
doboz.classList.remove("kiemelt");  // eltávolítja
doboz.classList.toggle("kiemelt");  // ha van, elveszi; ha nincs, hozzáadja
Miért jó ez? a stílust a CSS-ben írod meg egyszer, a JavaScript csak az osztályt kapcsolgatja. Így a kód rendezettebb marad.

Mikor használd a textContent-et, és mikor az innerHTML-t?

  • textContent: egyszerű szöveget ír be. Ezt használd általában.
  • innerHTML: HTML-kódot is beír. Csak akkor, ha tudod, hogy a tartalom biztonságos, mert idegen szöveg beírásakor veszélyes lehet.
Szabály: felhasználótól érkező szöveget soha ne tegyél innerHTML-be, mindig textContent-be.

4. Új elem létrehozása

A JavaScript új elemeket is tud létrehozni, és az oldalhoz adni:

const lista = document.querySelector("#lista");

const uj = document.createElement("li");   // új li elem
uj.textContent = "Ez egy új sor";
lista.appendChild(uj);                     // hozzáadás a lista végére

Ezzel tudod majd később kirajzolni a zenekönyvtár számait, mindegyikhez egy sor.

1. feladat: Készíts egy <ul id="lista"></ul> listát, és egy gombot. Minden gombnyomásra adj hozzá egy új sort, amely a sorszámát írja ki: „1. elem”, „2. elem” és így tovább.

5. A hang: az audio elem

A böngészőben a hangot az <audio> elem szólaltatja meg. Ez az elem nem látszik, csak a hangot játssza le. A JavaScriptből ezeket a parancsokat használod:

  • src: a hangfájl címe, amit le kell játszani.
  • play(): elindítja a lejátszást.
  • pause(): megállítja.
  • currentTime: hány másodpercnél tart a lejátszás.
  • duration: a szám teljes hossza másodpercben.
  • paused: igaz (true), ha áll; hamis (false), ha szól.
<audio id="lejatszo" src="pelda.mp3"></audio>
<button id="play">Lejátszás</button>

<script>
  const lejatszo = document.querySelector("#lejatszo");
  const play = document.querySelector("#play");

  play.addEventListener("click", () => {
    lejatszo.play();
  });
</script>
Fontos szabály: a böngészők nem engedik, hogy a hang magától, gombnyomás nélkül elinduljon. Ezért a play()-t mindig egy kattintás (vagy billentyűlenyomás) eseményében hívd meg.

6. Fájl betöltése a számítógépről

A felhasználó a saját fájljait egy <input type="file"> elemmel választja ki. A kiválasztás után a change esemény fut le:

<input type="file" id="fajl" accept="audio/*">

<script>
  const fajl = document.querySelector("#fajl");

  fajl.addEventListener("change", () => {
    const kivalasztott = fajl.files[0];   // az első kiválasztott fájl
    console.log("Kiválasztva:", kivalasztott.name);
  });
</script>

A fájlt a URL.createObjectURL teszi olyan címmé, amelyet az audio elem le tud játszani:

const cim = URL.createObjectURL(kivalasztott);
lejatszo.src = cim;

7. Állapot kijelzése és az idő

Ha a lejátszás közben az időt is szeretnéd kiírni, a setInterval függvény ismételten lefuttat egy kódot. Ez a 500 milliszekundumonként futó frissítés:

setInterval(() => {
  const eltelt = Math.floor(lejatszo.currentTime);
  const perc = Math.floor(eltelt / 60);
  const mp = String(eltelt % 60).padStart(2, "0");
  kijelzo.textContent = perc + ":" + mp;
}, 500);

A Math.floor lefelé kerekít, a % a maradékot adja, a padStart pedig a másodperceket két számjegyre egészíti ki, így „1:05” lesz „1:5” helyett.

Tipp: ha a böngésző F12-es Konzoljába írsz console.log(lejatszo.currentTime)-ot, azonnal látod, hogy működik-e a parancs.

8. Feladatok

2. feladat (közös): Készíts egy oldalt, amely:
  • egy fájlválasztóval betölt egy hangfájlt,
  • tartalmaz Lejátszás, Szünet és Újrakezdés gombot,
  • a gombok után azt mutatja, hogy szól-e vagy áll,
  • az eltelt időt „perc:másodperc” formában kiírja.
Az Újrakezdés gomb állítsa a currentTime-ot nullára, és indítsa újra a lejátszást.
3. feladat (bónusz): A gomb legyen kettős funkciójú: ha szól a zene, megállítsa, ha áll, elindítsa. A szöveg a gomb feliratán változzon: „Szünet” vagy „Lejátszás”. Itt a paused tulajdonságot használd.
