1. Mi az a BPM?

A BPM (beats per minute, ütem percenként) azt mutatja, hány ütem van egy perc alatt. Egy 120 BPM-es szám másodpercenként két ütemet ad. Egy ütem hossza így számolható:

const beat = 60 / bpm;   // egy ütem hossza másodpercben
// 120 BPM esetén: 60 / 120 = 0,5 másodperc

A DJ-zésben a BPM azt határozza meg, mikor kezdődjön a következő szám, és meddig tartson a hurok.

2. A tempó becslése: a lüktetés mérése

A számítógép a hangból nem tudja közvetlenül a BPM-et. Azt mérheti meg, hol erősödik hirtelen a hang, mert az ütemek ilyenkor szólalnak meg. Ez a lüktetés (onset) erőssége. Ha ezek egy szabályos ritmust mutatnak, a legerősebb ismétlődési távolság adja a BPM-et.

Az egyszerűsített módszer három lépésből áll:

  1. A hangot kis részekre bontjuk, és minden részre kiszámoljuk az energiát.
  2. Megnézzük, mennyivel nő az energia a következő részben. Ez a lüktetés erőssége.
  3. Végigpróbáljuk a lehetséges tempókat, és azt választjuk, amelyiknél a lüktetések a legjobban egybeesnek.
// A lüktetés-sorozat (onset) minden elemére:
// hány ütem távolságban ismétlődik? A legtöbb egybeesés adja a BPM-et.
function becsulBpm(onset, frissFrekvencia) {
  let legjobb = 0, bpm = 120;
  for (let c = 70; c <= 180; c += 0.5) {
    const tavolsag = Math.round(60 * frissFrekvencia / c);   // mintavétel per ütem
    let osszeg = 0;
    for (let f = 0; f + tavolsag < onset.length; f++) {
      osszeg += onset[f] * onset[f + tavolsag];
    }
    if (osszeg > legjobb) { legjobb = osszeg; bpm = c; }
  }
  return bpm;
}
Gyakori hiba: a becslés a felezett vagy duplázott tempót is adhatja. Egy 140 BPM-es szám 70 vagy 280 is lehet, ha a ritmust rosszul értelmezi. Ezért a kódban a tempót mindig visszahozzuk 80 és 160 közé.

3. TAP: a kézi tempó

Ha az automatikus érték téved, kézzel is megadhatod. Minden kattintás időpontját eltárolod, és a különbségeik átlagából számolsz BPM-et:

const tapok = [];

function tap() {
  const most = performance.now();          // a kattintás időpontja ezredmásodpercben
  tapok.push(most);
  // a 3 másodpercnél régebbi kopogásokat eldobjuk
  while (tapok.length > 0 && most - tapok[0] > 3000) tapok.shift();
  if (tapok.length < 2) return;

  let osszeg = 0;
  for (let i = 1; i < tapok.length; i++) osszeg += tapok[i] - tapok[i - 1];
  const atlag = osszeg / (tapok.length - 1);   // átlagos távolság ezredmásodpercben
  return 60000 / atlag;                       // BPM
}
Miért jó a performance.now()? Ez egy nagy pontosságú óra, amely ezredmásodperc tört részéig megadja az időt. A Date.now() pontatlanabb.

4. Effektív tempó: a sebesség beszámítása

Ha a tempófaderrel lassítasz vagy gyorsítasz, a szám tényleges tempója is változik. Ezt az effektív tempónak hívjuk. Ez a két szám szorzata:

const effektiv = alapBpm * zene.playbackRate;
// pl. 120 BPM alap, 1,1-es sebesség: 120 * 1,1 = 132 BPM

Fontos, hogy a kijelzőn mindig az effektív tempó látszódjon, mert ez az, amit a hallgató hall.

5. Loop: a pontos hurok

A hurok (loop) egy kis szakaszt ismétel. A pontos hossz ütemekből számolódik: 4 ütem hurokhoz 4 * beat másodperc kell.

function hurokIndit(d) {
  const beat = 60 / (effektiv(d) || 120);   // ha nincs tempó, 120-at feltételezünk
  d.hurokKezdet = d.zene.currentTime;
  d.hurokVeg = d.hurokKezdet + 4 * beat;
  d.hurok = true;
}

// minden képkockánál:
if (d.hurok && !d.zene.paused && d.zene.currentTime >= d.hurokVeg) {
  d.zene.currentTime = d.hurokKezdet;   // vissza az elejére
}
Egyszerű szabály: az ütemek pontos hosszából számítsd a hurkot, ne találgass időt másodpercben.

6. SYNC: két deck összehangolása

A SYNC azt jelenti, hogy a második deck sebességét úgy állítjuk, hogy a tempója megegyezzen az elsőével. Az effektív tempók hányadosából számolunk:

// A cél: a B effektív tempója legyen egyenlő az A effektív tempójával
const cel = effektiv(A);                 // pl. 128 BPM
const rata = cel / B.alapBpm;            // mennyivel kell gyorsítani a B-t
B.zene.playbackRate = rata;

Ha a sebesség túl nagy vagy kicsi (például 1,6-szoros), a hallható hang szétesik. Ezért a tempófaderek általában ±16%-ot engednek, és a SYNC csak ezen belül működik.
