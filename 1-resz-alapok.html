1. Előkészületek

A tanuláshoz számítógép kell, a telefon nehézkesebb a kódíráshoz. Szükséged lesz:

  • Böngésző: Chrome vagy Edge. Ebben futtatod a programokat.
  • Szövegszerkesztő: a Visual Studio Code ingyenes, és sok segítséget ad a kódíráshoz. Letöltés: code.visualstudio.com.
  • Egy mappa: hozz létre egy új mappát, például javascript-tanulas néven. Ide kerülnek a fájljaid.
Tipp: a kódot mindig a böngészőben futtatva próbáld ki. Ha valami nem működik, a böngésző mindig jelez, miért, az F12 gombbal megnyitható „Konzol” fül pedig megmutatja a hibaüzeneteket.

2. Mi a HTML, a CSS és a JavaScript?

Egy weboldal három nyelv együttműködésével készül. Egy hasonlat segíthet: egy ház építéséhez falra, festékre és villanyra van szükség.

  • HTML a szerkezet. Ez a falak és az ajtók: milyen elemek vannak az oldalon, például címsor, gomb vagy kép.
  • CSS a megjelenés. Ez a festés és a bútorok: színek, betűk, elrendezés.
  • JavaScript a viselkedés. Ez az elektromosság: a gomb megnyomására mit történik, mit számol, mit mutat.

A pultunkban is pont ez a három rész működik együtt: a HTML adja a gombokat és csúszkákat, a CSS a kinézetet, a JavaScript a hangot és a keverést.

3. Az első oldalad

Hozz létre egy index.html nevű fájlt a mappában, és írd bele:

<!doctype html>
<html lang="hu">
<head>
  <meta charset="utf-8">
  <title>Az első oldalam</title>
</head>
<body>
  <h1>Helló, világ!</h1>
  <p>Ez az első bekezdésem.</p>
</body>
</html>

Nyisd meg a fájlt a böngészőben duplakattintással. Látnod kell a címsort és a bekezdést.

Mit jelentenek a „<” jelek? A HTML-ben az elemeket kisebb- és nagyobb jelek között írjuk, például <h1> nyitja a címsort, </h1> zárja. Ezek a „címkék”.

A JavaScript a HTML-be kerül

A JavaScript kódot a <script> elemen belül írjuk, általában a </body> elé:

<script>
  console.log("Ez a JavaScript üzenete");
</script>

A console.log üzenetet ír a Konzolba. Az F12 gombbal nyisd meg, és az üzenetet ott fogod látni.

1. feladat: Írj be egy saját szöveget a console.log-ba, mentsd el, és töltsd újra az oldalt. Megjelenik?

4. Változók: adatok eltárolása

A változó egy doboz, amibe adatot teszel, és később név alapján visszakeresheted. Így kezdődik:

let nev = "Anna";
let eletkor = 25;
let kedvencZene = "house";
console.log(nev);
console.log(eletkor);
Anna
25

let és const

  • let: a változó értéke később megváltoztatható.
  • const: a változó értéke állandó, nem írható felül.
const uzenet = "Szia";   // ezt később nem lehet átírni
let pontszam = 0;        // ezt később igen
pontszam = pontszam + 1; // most már 1
console.log(pontszam);   // 1
Szabály: alapértelmezésként const-t használj. Csak akkor válts let-re, ha tudod, hogy az érték változni fog.

Adattípusok

  • Szám: 12, 3.5, -7
  • Szöveg: "Helló", idézőjelek között
  • Logikai érték: true (igaz) vagy false (hamis)
let bpm = 128;             // szám
let cim = "Party mix";     // szöveg
let lejatszas = false;     // logikai érték
console.log(bpm + 2);      // 130
console.log(cim + " 2");   // Party mix 2
Gyakori hiba: a szöveget mindig idézőjelbe kell tenni. A "128" szöveg, nem szám, ezzel nem lehet számolni.
2. feladat: Hozz létre három változót: a kedvenc számod címét, a BPM-jét és azt, hogy lejátszás alatt van-e. Írd ki mindhármat a Konzolba.

5. Feltételek: döntések a programban

Az if (ha) és az else (különben) a program döntéseit írja le:

let hangero = 70;

if (hangero > 90) {
  console.log("Túl hangos!");
} else if (hangero < 10) {
  console.log("Túl halk!");
} else {
  console.log("Jó a hangerő.");
}
Jó a hangerő.

Összehasonlító jelek

  • === egyenlő
  • !== nem egyenlő
  • > nagyobb, < kisebb
  • >= nagyobb vagy egyenlő, <= kisebb vagy egyenlő
  • && és (mindkettőnek igaznak kell lennie), || vagy (legalább az egyik igaz)
let lejatszas = true;
let hangero = 50;

if (lejatszas === true && hangero > 0) {
  console.log("A zene szól.");
}
Gyakori hiba: egyenlőségnél mindig három egyenlőségjel kell: ===. Az egy egyenlőségjel értéket ad, nem hasonlít össze.

6. Függvények: újrahasznosítható kódrészek

A függvény egy névvel ellátott kódcsomag. Ha többször kell ugyanazt csinálni, ezt írjuk meg egyszer:

function udvozol(nev) {
  return "Szia, " + nev + "!";
}

console.log(udvozol("Péter"));  // Szia, Péter!
console.log(udvozol("Lili"));   // Szia, Lili!

A nev a függvény paramétere: ezt adod át bemenetként. A return a visszatérési érték, ezt kapod vissza.

Nyílfüggvény: a rövidebb forma

A mai kódban gyakran látsz nyílfüggvényt, ez ugyanazt csinálja, csak rövidebben:

const duplaz = (szam) => szam * 2;
console.log(duplaz(4));  // 8
3. feladat: Írj egy függvényt, amely két számot kap, és visszaadja az összegüket. Hívd meg háromféle számpárral, és írd ki az eredményeket.

7. Gombok és események: a program reagál

Eddig a kódunk magától futott. A valódi programok a felhasználóra reagálnak: gombnyomásra, csúszka mozgatásra, billentyűre. Ehhez három dolog kell:

  1. Gomb a HTML-ben: <button id="gomb">Kattints</button>
  2. Az elem kiválasztása a JavaScriptben: document.querySelector("#gomb")
  3. Esemény figyelése: addEventListener("click", függvény)
<button id="gomb">Kattints ide</button>
<p id="uzenet"></p>

<script>
  const gomb = document.querySelector("#gomb");
  const uzenet = document.querySelector("#uzenet");

  gomb.addEventListener("click", () => {
    uzenet.textContent = "Megnyomtad a gombot!";
  });
</script>
Az id: a HTML-elemek kapnak egy azonosítót, az id-t. A JavaScript ezzel talál meg egy elemet. A # jel a kiválasztáskor azt jelenti, hogy „azonosító szerint keresek”.

Számláló: az első valódi mini-program

<button id="plusz">+1</button>
<p>Pontszám: <span id="ertek">0</span></p>

<script>
  let pontszam = 0;
  const plusz = document.querySelector("#plusz");
  const ertek = document.querySelector("#ertek");

  plusz.addEventListener("click", () => {
    pontszam = pontszam + 1;
    ertek.textContent = pontszam;
  });
</script>

Minden kattintásra a pontszam változó nő eggyel, és a képernyőn is frissül.

4. feladat: Adj hozzá egy „-1” gombot is, ami csökkenti a pontszámot. Figyelj arra, hogy a 0 alá ne menjen.

8. Ciklusok: ismétlés

Ha ugyanazt többször kell megcsinálni, ciklust használunk. Például öt számot írunk ki:

for (let i = 1; i <= 5; i++) {
  console.log("Ez a(z) " + i + ". sor.");
}
Ez a(z) 1. sor.
Ez a(z) 2. sor.
Ez a(z) 3. sor.
Ez a(z) 4. sor.
Ez a(z) 5. sor.

A for három részből áll: a kezdőérték, a feltétel, és a lépés. Addig fut, amíg a feltétel igaz.

5. feladat: Írj egy ciklust, ami kiírja a 2, 4, 6, … 20 számokat.

9. Tömbök és objektumok: rendezett adatok

Tömb: számok vagy szövegek listája

const szamok = [10, 20, 30];
console.log(szamok[0]);       // 10, az első elem
console.log(szamok.length);   // 3, a db
szamok.push(40);              // hozzáadás a végére
console.log(szamok);          // [10, 20, 30, 40]

Objektum: egy dolog tulajdonságai

Az objektum kulcs és érték párokat tárol. Ezzel írjuk le például egy számot:

const szam = {
  cim: "Party mix",
  eloado: "DJ Példa",
  bpm: 128
};
console.log(szam.cim);     // Party mix
console.log(szam.bpm);     // 128

Tömb bejárása

const szamok = ["Első", "Második", "Harmadik"];
szamok.forEach((elem) => {
  console.log(elem);
});

A pultunkban a zenekönyvtár is egy tömb, a számokat objektumként tároljuk, és egy ciklussal rajzoljuk ki őket a képernyőre.

10. Összefoglaló és első önálló feladat

Most már tudod:

  • hogy a HTML, CSS és JavaScript hogyan viszonyul egymáshoz,
  • hogyan írj változókat, feltételeket és függvényeket,
  • hogyan reagál a program gombnyomásra,
  • hogyan ismételsz ciklussal, és hogyan tárolsz listát vagy objektumot.
Önálló feladat: készíts egy oldalt, amelyen van egy Lejátszás és egy Szünet gomb, és egy szöveg, ami azt mutatja: „Szól” vagy „Áll”. A gombok állítsák a szöveget. Ha elakadsz, írd meg a kódodat, és segítek megtalálni a hibát.
