1. Mi az a MIDI?

A MIDI (Musical Instrument Digital Interface) egy régi, szabványos nyelv a zenei eszközök között. A vezérlő nem hangot küld, hanem üzeneteket: „a 3-as gombot megnyomták”, vagy „a csúszkát 90-es értékre állították”.

Egy üzenet mindig három számból áll:

RészJelentésPélda
StátuszMi történt, és melyik csatornán0xB0 = csúszka/forgatógomb (CC), 0x90 = gomb lenyomása (Note On)
Adat 1Melyik gomb vagy csúszkapl. 7-es szám a hangerő-csúszka
Adat 2Mekkora az érték0 és 127 között

A státusz bájt alsó 4 bitje a csatorna száma (0–15), a felső 4 bit a típus. Ezért a típust így szedjük ki:

const tipus = statusz & 0xF0;        // a felső 4 bit: a típus
const csatorna = (statusz & 0x0F) + 1; // az alsó 4 bit: a csatorna (1–16)
Mit jelent az &? Ez a bitenkénti „és” művelet. Azt használjuk, hogy egy számból csak a kívánt biteket tartsuk meg. A kezdőknek elég annyit tudni, hogy a statusz & 0xF0 eltünteti a csatornaszámot.

2. A böngésző és a MIDI: a Web MIDI API

A böngészőben a MIDI-eszközöket a navigator.requestMIDIAccess() kéri le. A böngésző ilyenkor engedélyt kér a felhasználótól:

async function midiIndit() {
  const hozzaferes = await navigator.requestMIDIAccess();

  hozzaferes.inputs.forEach(eszkoz => {
    eszkoz.onmidimessage = midiKezel;   // minden üzenetnél ez a függvény fut
  });
  console.log("MIDI kész");
}
Fontos korlátok: a Web MIDI csak HTTPS-en (vagy helyi gépen) működik. Chrome, Edge és Android Chrome támogatja, az iPhone Safari nem. Ha az alkalmazást telefonon, iPhone-on használod, a MIDI-vezérlő nem fog működni, ezt érdemes a felhasználóknak előre megírni.

3. Az üzenet felbontása

A onmidimessage minden üzenetnél egy eseményt ad át. Az üzenet adatai az esemeny.data listában vannak:

function midiKezel(esemeny) {
  const [statusz, adat1, adat2] = esemeny.data;   // a három szám
  const tipus = statusz & 0xF0;

  if (tipus === 0xB0) {
    console.log("Csúszka", adat1, "értéke:", adat2);
  }
  if (tipus === 0x90 && adat2 > 0) {
    console.log("Gomb", adat1, "lenyomva");
  }
}

Vegyük észre: a Note On üzenetnek a 2. adata (a sebesség) is lehet 0. Ez azt jelenti, hogy a gombot elengedték. Ezért a adat2 > 0 ellenőrzés fontos.

4. Értékek átalakítása: 0–127 és 0–1

A MIDI-csúszkák értéke 0 és 127 közötti egész szám. A programodban viszont a hangerő általában 0 és 1 közötti tört. Ezért át kell alakítani:

const normal = adat2 / 127;          // 0 → 0, 127 → 1, 64 → kb. 0,5
const hangero = Math.min(1, Math.max(0, normal));  // biztosan 0 és 1 között marad

A Math.max és Math.min az értéket a határok közé szorítja. Így hiba esetén sem lesz túl nagy vagy túl kicsi a hangerő.

5. MIDI learn: a kötések tárolása

A MIDI learn azt jelenti, hogy a felhasználó megnyom egy gombot a programban, majd a vezérlőn is megnyom egy gombot, és a program megjegyzi a kettő kapcsolatát. A kötéseket egy objektumban tároljuk. A kulcs a típusból és az adat1-ből áll:

let tanul = null;     // ha nem null, a következő üzenetet ehhez kötjük
let kotesek = {};     // pl. { "176-7": "fader", "144-60": "play" }

function kulcs(tipus, adat1) {
  return tipus + "-" + adat1;   // pl. 176-7
}

A kötések a böngészőben is megmaradnak, ha a localStorage-ba mentjük. Figyelj arra, hogy ezt a try blokkba tedd, mert egyes böngészőkben a tárolás nem érhető el:

function kotesekMentese() {
  try {
    localStorage.setItem("kotesek", JSON.stringify(kotesek));
  } catch (e) {
    console.log("Nem sikerült menteni");
  }
}

A midiKezel függvény így lesz kiegészítve:

function midiKezel(esemeny) {
  const [statusz, adat1, adat2] = esemeny.data;
  const tipus = statusz & 0xF0;
  const k = kulcs(tipus, adat1);

  if (tanul) {                 // tanulási mód: ezt az üzenetet kötjük hozzá
    kotesek[k] = tanul;
    kotesekMentese();
    tanul = null;
    return;
  }

  const cel = kotesek[k];      // melyik funkcióhoz tartozik?
  if (cel === "fader" && tipus === 0xB0) {
    hangeroBeallit(adat2 / 127);
  }
  if (cel === "play" && tipus === 0x90 && adat2 > 0) {
    lejatszasKapcsol();
  }
}
Miért jó ez a szerkezet? A program nem tudja előre, melyik gomb melyik vezérlőről jön. A kötések táblázata választja szét a „hardvert” és a „funkciót”. Így ugyanaz a kód bármilyen márkájú vezérlővel működik, csak a kötéseket kell újra tanítani.

6. Billentyűzet: a keydown esemény

A billentyűket a keydown eseménnyel figyeljük. Az e.code a fizikai billentyűt adja meg (például "Space", "KeyQ", "ArrowUp"), ez nem függ a billentyűzet nyelvétől:

document.addEventListener("keydown", (e) => {
  // ha éppen szövegmezőbe írunk, ne reagáljunk a billentyűkre
  if (e.target.tagName === "INPUT" || e.target.tagName === "TEXTAREA") return;

  // a lenyomva tartott billentyű ismétléseit kihagyjuk
  if (e.repeat) return;

  if (e.code === "Space") {
    e.preventDefault();        // ne görgessen az oldal
    lejatszasKapcsol();
  }
  if (e.code === "ArrowUp") {
    hangeroBeallit(hangero + 0.05);
  }
});
Gyakori hiba: ha nem nézed meg az e.repeat-et, a lenyomva tartott billentyű sok eseményt küld, és a program hibásan sokszor fut le. Mindig tedd be ezt az ellenőrzést a billentyűkezelésbe.
