1. Miért ne másoljuk a kódot?

Ha a második lejátszóhoz bemásolod az elsőhöz írt kódot, és átírod a neveket, két probléma van. Először: ha később változtatni kell valamin, mindkét helyen át kell írni. Másodszor: könnyen elírsz valamit az egyik példányban. A jobb megoldás, hogy egyetlen függvényt írsz, és azt többször meghívod.

Alapelv: ha ugyanazt a kódot kétszer írod le, az már jel, hogy függvényt kellene írnod.

2. Adatattribútumok: data-*

A HTML-elemekre a data- kezdetű attribútumokat is írhatunk. Ezek olyan jelölések, amelyeket a JavaScript könnyen megtalál, és a CSS nem használ:

<button data-play>Lejátszás</button>

<script>
  const gomb = document.querySelector("[data-play]");
</script>

Így nem kell minden gombnak egyedi id-t adni, és egy csoportban lévő elemeket egységesen tudsz kezelni.

3. A csúszka: range és az input esemény

A csúszka egy <input type="range"> elem. Megadod a legkisebb és a legnagyobb értéket, és a kezdőértéket:

<input type="range" min="0" max="100" value="80">

Amikor a felhasználó mozgatja, az input esemény fut le. Ezt a click helyett használjuk:

const csuszka = document.querySelector("[data-hangero]");

csuszka.addEventListener("input", () => {
  console.log("Most: " + csuszka.value);
});
Fontos: a value mindig szövegként érkezik. Számmá kell alakítani, ha számolni akarsz vele: például Number(csuszka.value), vagy egyszerűen csuszka.value / 100, mert a szorzás és osztás automatikusan számmá alakítja.

4. Függvény, ami egy egész deckot beállít

A deck egy HTML-csoport: fájlválasztó, lejátszó, gombok, csúszkák, állapot. Egy függvénnyel mindezt egyszerre kezelhetjük. A függvény egy elemet kap, és a belső elemeket a querySelector segítségével keresi meg:

function allitsBe(deckElem) {
  const fajl = deckElem.querySelector("[data-fajl]");
  const lejatszo = deckElem.querySelector("[data-lejatszo]");
  // ... további elemek és eseménykezelők
}

A deckElem.querySelector csak a megadott deckben keres, nem az egész oldalon. Ez az, ami miatt a két deck nem keveredik össze.

5. Sablonstringek: a template literal

Ha dinamikusan szeretnél szöveget összerakni, a visszafelé idézőjel (backtick, `) és a ${} jelölés a legkényelmesebb:

const deck = "a";
const azonosito = `#${deck}-lejatszo`;   // "#a-lejatszo"
console.log(`Ez a(z) ${deck} deck.`);     // Ez a(z) a deck.
Összehasonlítás: a régi, + jelekkel összerakott módszer ugyanezt tudja, de a sablonstring olvashatóbb.

6. Több elem egyszerre: forEach

Az oldalon két deck van. A querySelectorAll mindkettőt megadja, a forEach pedig mindegyikre lefuttatja a függvényt:

document.querySelectorAll(".deck").forEach(allitsBe);

Ez az egy sor két decket állít be, és ha később egy harmadikat adsz az oldalhoz, az is automatikusan működik.

7. A hangerő és a tempó

Az audio elemnek két fontos tulajdonsága van, amit a csúszkával állíthatsz:

  • volume: a hangerő 0 és 1 között. Ha a csúszka 0–100, akkor a value / 100.
  • playbackRate: a lejátszás sebessége. 1 a normál, 0,5 a lassú, 1,5 a gyors. A csúszkából a value / 100 adja meg.

<div class="deck">
  <h3>A deck</h3>
  <input type="file" accept="audio/*" data-fajl>
  <audio data-lejatszo></audio>
  <p><button data-play>Lejátszás</button> <button data-szunet>Szünet</button></p>
  <label>Hangerő <input type="range" min="0" max="100" value="80" data-hangero></label>
  <label>Tempó <input type="range" min="50" max="150" value="100" data-tempo></label>
  <p data-allapot>Nincs dal betöltve</p>
</div>

<!-- A B deck ugyanígy, csak a másolat -->

<script>
  function allitsBe(deckElem) {
    const fajl = deckElem.querySelector("[data-fajl]");
    const lejatszo = deckElem.querySelector("[data-lejatszo]");
    const play = deckElem.querySelector("[data-play]");
    const szunet = deckElem.querySelector("[data-szunet]");
    const hangero = deckElem.querySelector("[data-hangero]");
    const tempo = deckElem.querySelector("[data-tempo]");
    const allapot = deckElem.querySelector("[data-allapot]");

    fajl.addEventListener("change", () => {
      const kivalasztott = fajl.files[0];
      if (!kivalasztott) return;
      lejatszo.src = URL.createObjectURL(kivalasztott);
      allapot.textContent = "Betöltve: " + kivalasztott.name;
    });

    play.addEventListener("click", () => {
      if (!lejatszo.src) {
        allapot.textContent = "Előbb tölts be egy dalt!";
        return;
      }
      lejatszo.play();
      allapot.textContent = "Szól";
    });

    szunet.addEventListener("click", () => {
      lejatszo.pause();
      allapot.textContent = "Áll";
    });

    hangero.addEventListener("input", () => {
      lejatszo.volume = hangero.value / 100;
    });

    tempo.addEventListener("input", () => {
      lejatszo.playbackRate = tempo.value / 100;
    });
  }

  document.querySelectorAll(".deck").forEach(allitsBe);
</script>
Gyakori hiba: ha a lejátszó még nincs fájllal, a play() hibát dob. Ezért ellenőrizzük előre az if (!lejatszo.src) feltétellel.
1. feladat: Adj a két deckhez egy-egy „Újrakezdés” gombot. Ez állítsa a currentTime-ot nullára, és indítsa a lejátszást.
2. feladat: A tempó csúszka mellett jelenjen meg egy szöveg, ami a tényleges sebességet mutatja, például „1,25×”. A szöveg a csúszka mozgatásakor frissüljön.
3. feladat (bónusz): Írj egy harmadik decket is, a kódot ne másold, csak a HTML-t adj hozzá, és ellenőrizd, hogy a függvény automatikusan beállítja-e. Ha igen, megértetted a forEach működését.
