Hangkeverés

4. rész a sorozatból. Eddig a hangerőt és a tempót az audio elem saját tulajdonságaival állítottuk. Ez a rész a Web Audio API-ra épül: ez egy böngészőbe beépített hangmotor, amely a hangot lépésenként, egymás után kapcsolt „dobozokon” vezeti át. Ezzel tudod majd az EQ-t, a crossfadert és a főhangerőt is megvalósítani.

Tartalomjegyzék

  1. A hangmotor: az AudioContext
  2. A hangforrás: createMediaElementSource
  3. A hangrészek lánca: connect
  4. GainNode: hangerő
  5. BiquadFilterNode: EQ-sávok
  6. Crossfader: az egyenlő teljesítményű átmenet
  7. Teljes kód és feladatok

1. A hangmotor: az AudioContext

Minden Web Audio programot egy AudioContext nevű hangmotor kezd el. Ezt egyszer hozod létre:

const ctx = new (window.AudioContext || window.webkitAudioContext)();

A böngészők a hangmotort első gombnyomásig felfüggesztve tartják. Ezért a kódban mindig van egy ctx.resume() hívás egy kattintás eseményben:

lejatszasGomb.addEventListener("click", () => {
  ctx.resume();
  lejatszo.play();
});
Szabály: a hangmotort csak felhasználói kattintás után lehet elindítani, különben a böngésző csendben tartja.

2. A hangforrás: createMediaElementSource

Az audio elemet hozzá kell kötni a hangmotorhoz. Ezt a createMediaElementSource teszi:

const forras = ctx.createMediaElementSource(lejatszo);
Fontos: egy audio elemhez csak egyszer lehet forrást létrehozni. Ha kétszer hívod, hibát kapsz. Ezért a beállítást egyszer, az oldal betöltésekor végezd el.

3. A hangrészek lánca: connect

A Web Audio programban a részek „dobozok”, amelyeket egymás után kötünk össze a connect paranccsal. A hang a forrásból indul, és a végső kimenetig halad:

forras.connect(hangero).connect(ctx.destination);

A ctx.destination a hangszóró vagy a fejhallgató. Ezt a láncot szemléltetheti egy vízcső: a víz a forrástól a csapig folyik, és minden szűrő vagy szelep a láncban módosítja az áramlást.

Lényeg: a connect láncolható: a.connect(b).connect(c) egyenértékű azzal, hogy a-t b-hez, b-t c-hez köted.

4. GainNode: hangerő

A createGain() egy hangerő-csomópontot ad. Az értéke a gain.value:

const hangero = ctx.createGain();
hangero.gain.value = 0.5;   // fél hangerő
hangero.gain.value = 1;     // normál
hangero.gain.value = 0;     // néma

Simább változás: setTargetAtTime

Ha a csúszkát azonnal állítod, a hang kattanhat. Erre a setTargetAtTime való: a változás fokozatosan történik.

hangero.gain.setTargetAtTime(0.8, ctx.currentTime, 0.03);

A harmadik szám a simítás idejét adja másodpercben. A ctx.currentTime a hangmotor saját órája.

5. BiquadFilterNode: EQ-sávok

A szűrő a hangot frekvenciák szerint alakítja. Három fő típus kell az EQ-hoz:

  • lowshelf: a mély hangokat emeli vagy vágja
  • peaking: egy középső sávot emel vagy vág
  • highshelf: a magas hangokat emeli vagy vágja
const mely = ctx.createBiquadFilter();
mely.type = "lowshelf";
mely.frequency.value = 250;   // a vágási pont Hz-ben
mely.gain.value = 0;          // decibel: 0 = nincs változás, +12 erősít, -12 gyengít

const kozep = ctx.createBiquadFilter();
kozep.type = "peaking";
kozep.frequency.value = 1000;
kozep.Q.value = 1;            // a sáv szélessége
kozep.gain.value = 0;

const magas = ctx.createBiquadFilter();
magas.type = "highshelf";
magas.frequency.value = 4000;
magas.gain.value = 0;

A csúszka értékéből a decibelt így kapod: (csuszkaErtek - 50) / 50 * 12, ha a csúszka 0–100 között mozog. Ez -12 és +12 dB közötti értéket ad.

Láncolva: forras.connect(mely).connect(kozep).connect(magas).connect(hangero).connect(ctx.destination) — ez már egy teljes, EQ-val ellátott sáv.

6. Crossfader: az egyenlő teljesítményű átmenet

A crossfader két deck közötti keverés. Ha egyszerűen lineárisan csökkented az egyik és növeled a másik hangerejét, a közepén a hang halkabbnak tűnik. Erre a jobb megoldás a koszinusz-szinusz párosítás, amely egyenlő teljesítményt tart:

// x értéke 0 és 1 között: 0 = csak A, 1 = csak B, 0,5 = középen
const gainA = Math.cos(x * Math.PI / 2);
const gainB = Math.sin(x * Math.PI / 2);
Ellenőrzés: x = 0 → A = 1, B = 0. x = 1 → A = 0, B = 1. x = 0,5 → mindkettő körülbelül 0,707, ami együtt egyenletes hangerőt ad.

7. Teljes kód és feladatok

Az alábbi oldal két decket köt egy közös kimenetre, mindegyikhez EQ-t és hangerőt ad, a végén pedig egy crossfader keveri őket. Mentsd el index.html néven, és próbáld ki. A demóban a hangfájlt tudod betölteni mindkét decken.

<script>
  const ctx = new (window.AudioContext || window.webkitAudioContext)();

  // Közös kimenet: a főhangerő, majd a hangszóró
  const master = ctx.createGain();
  master.connect(ctx.destination);

  // A két deck kimenete a crossfaderhez
  const kimenetA = ctx.createGain();
  const kimenetB = ctx.createGain();
  kimenetA.connect(master);
  kimenetB.connect(master);

  function allitsBe(deckElem, kimenet) {
    const fajl = deckElem.querySelector("[data-fajl]");
    const lejatszo = deckElem.querySelector("[data-lejatszo]");
    const play = deckElem.querySelector("[data-play]");
    const szunet = deckElem.querySelector("[data-szunet]");
    const mely = deckElem.querySelector("[data-mely]");
    const kozep = deckElem.querySelector("[data-kozep]");
    const magas = deckElem.querySelector("[data-magas]");
    const hangero = deckElem.querySelector("[data-hangero]");
    const allapot = deckElem.querySelector("[data-allapot]");

    // EQ-sávok
    const melySav = ctx.createBiquadFilter();
    melySav.type = "lowshelf"; melySav.frequency.value = 250;
    const kozepSav = ctx.createBiquadFilter();
    kozepSav.type = "peaking"; kozepSav.frequency.value = 1000; kozepSav.Q.value = 1;
    const magasSav = ctx.createBiquadFilter();
    magasSav.type = "highshelf"; magasSav.frequency.value = 4000;

    const hangeroNode = ctx.createGain();

    // A forrás és a lánc. Ez egy elemhez csak egyszer készülhet.
    const forras = ctx.createMediaElementSource(lejatszo);
    forras.connect(melySav).connect(kozepSav).connect(magasSav).connect(hangeroNode).connect(kimenet);

    fajl.addEventListener("change", () => {
      const f = fajl.files[0];
      if (!f) return;
      lejatszo.src = URL.createObjectURL(f);
      allapot.textContent = "Betöltve: " + f.name;
    });

    play.addEventListener("click", () => {
      ctx.resume();
      if (!lejatszo.src) { allapot.textContent = "Előbb tölts be egy dalt!"; return; }
      lejatszo.play();
      allapot.textContent = "Szól";
    });

    szunet.addEventListener("click", () => {
      lejatszo.pause();
      allapot.textContent = "Áll";
    });

    // A csúszka 0–100 értékéből -12 és +12 dB lesz
    const dB = (csuszka) => (csuszka.value - 50) / 50 * 12;
    mely.addEventListener("input", () => { melySav.gain.setTargetAtTime(dB(mely), ctx.currentTime, 0.03); });
    kozep.addEventListener("input", () => { kozepSav.gain.setTargetAtTime(dB(kozep), ctx.currentTime, 0.03); });
    magas.addEventListener("input", () => { magasSav.gain.setTargetAtTime(dB(magas), ctx.currentTime, 0.03); });

    hangero.addEventListener("input", () => {
      hangeroNode.gain.setTargetAtTime(hangero.value / 100, ctx.currentTime, 0.03);
    });
  }

  allitsBe(document.querySelectorAll(".demo .deck")[0], kimenetA);
  allitsBe(document.querySelectorAll(".demo .deck")[1], kimenetB);

  // Crossfader: egyenlő teljesítményű átmenet
  const xfade = document.querySelector("#xfade");
  xfade.addEventListener("input", () => {
    const x = xfade.value / 100;
    kimenetA.gain.setTargetAtTime(Math.cos(x * Math.PI / 2), ctx.currentTime, 0.03);
    kimenetB.gain.setTargetAtTime(Math.sin(x * Math.PI / 2), ctx.currentTime, 0.03);
  });

  // Főhangerő
  const masterCsuszka = document.querySelector("#master");
  masterCsuszka.addEventListener("input", () => {
    master.gain.setTargetAtTime(masterCsuszka.value / 100, ctx.currentTime, 0.03);
  });
</script>
Gyakori hiba: ha a hang nem szól, nézd meg a Konzolt (F12). Ha „The AudioContext was not allowed to start” üzenet van, a ctx.resume() hiányzik, vagy nem kattintás eseményben van.
1. feladat: Adj a főhangerő csúszka mellé egy szöveget, amely a százalékos értéket mutatja, és a csúszkával együtt változik.
2. feladat: A crossfader szélső helyzetében az egyik deck teljesen néma legyen. Ellenőrizd a Konzolban a kimenetA.gain.value és a kimenetB.gain.value értékét.
3. feladat (bónusz): Egy AnalyserNode csomópontot kötj a főkimenetre, és számold ki a hangerő szintjét. Ehhez a createAnalyser() és a getByteTimeDomainData hívásokat használd.
Mi jön az 5. részben? A vizuális elemek: a forgó lemez, a hullámforma, és a hangerőmérő. Ezeket a requestAnimationFrame nevű függvénnyel valósítjuk meg, amely minden képkockánál lefut.
