Látvány és animáció

5. rész a sorozatból. Eddig a hangot irányítottuk. Most azt tanuljuk meg, hogyan lesz a programból látvány: forgó lemez, hullámforma és hangerőmérő. Ezekhez három új eszközt használunk: az animációs ciklust, a canvas rajzvásznat, és az elemzőt, amely a hangból mérőszámot ad.

Tartalomjegyzék

  1. Az animációs ciklus: requestAnimationFrame
  2. Mozgás időtől függően: a dt
  3. Forgó lemez: a CSS transform
  4. Rajzolás vászonra: a canvas
  5. Hullámforma: a hang csúcsértékei
  6. Hangerőmérő: az AnalyserNode
  7. Teljes kód és feladatok

1. Az animációs ciklus: requestAnimationFrame

A képernyő másodpercenként általában 60-szor frissül. Ha a JavaScriptben egy függvényt a requestAnimationFrame segítségével hívsz meg, az minden képkockánál lefut. Ez az animáció szíve:

function frissit() {
  // itt változtatod a képet
  requestAnimationFrame(frissit);   // kéri a következő képkockát
}
requestAnimationFrame(frissit);     // elindítja

A függvény végén újra meghívja magát a requestAnimationFrame. Ez így megy végtelenül, amíg az oldal nyitva van.

Hasonlat: egy filmkocka-sorozat. Minden kocka egy kicsit más, és a gyors egymásutánban látszik a mozgás.

2. Mozgás időtől függően: a dt

Ha minden képkockánál a lemezt például 2 fokkal forgatod, gyorsabb képernyőn gyorsabban forog. Jobb, ha az eltelt időt is figyeled, és az alapján számolsz. Ezt a dt (delta time, időkülönbség) mutatja:

let utolso = performance.now();

function frissit(most) {
  const dt = (most - utolso) / 1000;   // másodpercben az eltelt idő
  utolso = most;
  // például 90 fok másodpercenként:
  forgas = forgas + 90 * dt;
  requestAnimationFrame(frissit);
}

A most paramétert a böngésző adja, és ez az aktuális idő ezredmásodpercben. Így a forgás sebessége mindig 90 fok másodpercenként, a képernyő frissítési gyakoriságától függetlenül.

3. Forgó lemez: a CSS transform

A lemez egy div, amely CSS-szel kör alakú. A forgatást a transform tulajdonsággal végezzük, JavaScriptből:

const lemez = document.querySelector("#lemez");
lemez.style.transform = "rotate(" + forgas + "deg)";

A rotate fokokban forgat. A böngésző magától a közepe körül forgatja az elemet.

Gyakori hiba: a deg egység kell a szám után, különben a forgatás nem működik.

4. Rajzolás vászonra: a canvas

Ha több ezer pontot vagy vonalat kell kirajzolni, a canvas elem a legjobb. Ez egy üres rajzfelület, amelyre a JavaScriptből rajzolsz:

<canvas id="hullam" width="600" height="80"></canvas>

<script>
  const vaszon = document.querySelector("#hullam");
  const g = vaszon.getContext("2d");

  g.fillStyle = "#ff6fb1";           // a kitöltés színe
  g.fillRect(10, 10, 50, 30);        // x, y, szélesség, magasság
</script>

A clearRect törli a vásznat. Minden képkockánál először törölni kell, majd újra rajzolni.

5. Hullámforma: a hang csúcsértékei

A hullámforma a szám hangerőgörbéje. Ehhez a hangot először be kell olvasni, majd a csúcsértékeit kiszámolni. A decodeAudioData egy fájlt hangadattá alakít:

const arr = await fajl.arrayBuffer();
const buf = await ctx.decodeAudioData(arr);
const adat = buf.getChannelData(0);   // az első csatorna mintái

Az egész számot egy vonal-sorozatra kell felosztani. Minden szakasz legnagyobb értéke lesz egy oszlop magassága:

function felbontas(adat, n) {
  const resz = Math.floor(adat.length / n);
  const eredmeny = [];
  for (let i = 0; i < n; i++) {
    let max = 0;
    for (let j = 0; j < resz; j++) {
      const v = Math.abs(adat[i * resz + j]);
      if (v > max) max = v;
    }
    eredmeny.push(max);
  }
  return eredmeny;
}

Ezután minden oszlopot megrajzolsz, a lejátszott részt más színnel:

function rajzolHullam(arany) {   // arany: 0 és 1 között, a lejátszott rész
  g.clearRect(0, 0, vaszon.width, vaszon.height);
  peaks.forEach((ertek, i) => {
    const amp = ertek * vaszon.height / 2;
    g.fillStyle = (i / peaks.length <= arany) ? "#ff6fb1" : "#e6d9ee";
    g.fillRect(i, vaszon.height / 2 - amp, 1, amp * 2);
  });
}

6. Hangerőmérő: az AnalyserNode

Az elemző (AnalyserNode) a hang pillanatnyi értékeit adja vissza, így a hangerő kiszámolható. Ezt a hangmotor láncába kötöd, a hangszóró elé:

const elemzo = ctx.createAnalyser();
elemzo.fftSize = 256;
forras.connect(elemzo).connect(ctx.destination);

// minden képkockánál:
const adat = new Uint8Array(elemzo.fftSize);
elemzo.getByteTimeDomainData(adat);   // a jelszint értékei 0 és 255 között

let osszeg = 0;
for (const v of adat) {
  const x = (v - 128) / 128;         // -1 és 1 közé hozzuk
  osszeg += x * x;
}
const szint = Math.sqrt(osszeg / adat.length);   // RMS: a hangerő átlaga

Az RMS (átlagos négyzetes érték) egy szám, ami a hangerő valós érzetét adja. A mérő szélességét ebből számolod: szint * 300 százalék, de 100-nál nagyobb nem lehet.

Tipp: a Uint8Array minden képkockánál új tömböt foglal. Egy tanuló programban ez rendben van, később érdemes egyszer létrehozni, és újra felhasználni.

7. Teljes kód és feladatok

Az alábbi oldal egy lejátszót tartalmaz forgó lemezzel, hullámformával, hangerőmérővel és idő-kijelzéssel. Töltsd be a számodat a fájlválasztóval, és nézd meg, hogyan mozog minden.

0:00 / 0:00

<input type="file" id="fajl" accept="audio/*">
<div id="lemez"><div class="kozep"></div></div>
<canvas id="hullam" width="600" height="80"></canvas>
<div class="meter"><i id="szint"></i></div>
<button id="play">Lejátszás</button> <button id="szunet">Szünet</button>
<p id="ido">0:00 / 0:00</p>
<audio id="zene"></audio>

<script>
  const ctx = new (window.AudioContext || window.webkitAudioContext)();
  const zene = document.querySelector("#zene");
  const forras = ctx.createMediaElementSource(zene);

  const elemzo = ctx.createAnalyser();
  elemzo.fftSize = 256;
  forras.connect(elemzo).connect(ctx.destination);

  const lemez = document.querySelector("#lemez");
  const vaszon = document.querySelector("#hullam");
  const g = vaszon.getContext("2d");
  const szint = document.querySelector("#szint");
  const ido = document.querySelector("#ido");
  let peaks = [];
  let forgas = 0;
  let utolso = performance.now();

  function felbontas(adat, n) {
    const resz = Math.floor(adat.length / n);
    const eredmeny = [];
    for (let i = 0; i < n; i++) {
      let max = 0;
      for (let j = 0; j < resz; j++) {
        const v = Math.abs(adat[i * resz + j]);
        if (v > max) max = v;
      }
      eredmeny.push(max);
    }
    return eredmeny;
  }

  function rajzolHullam(arany) {
    g.clearRect(0, 0, vaszon.width, vaszon.height);
    peaks.forEach((ertek, i) => {
      const amp = ertek * vaszon.height / 2;
      g.fillStyle = (i / peaks.length <= arany) ? "#ff6fb1" : "#e6d9ee";
      g.fillRect(i, vaszon.height / 2 - amp, 1, amp * 2);
    });
  }

  function formaz(s) {
    if (!isFinite(s)) return "0:00";
    return Math.floor(s / 60) + ":" + String(Math.floor(s % 60)).padStart(2, "0");
  }

  document.querySelector("#fajl").addEventListener("change", async (e) => {
    const f = e.target.files[0];
    if (!f) return;
    zene.src = URL.createObjectURL(f);
    const buf = await ctx.decodeAudioData(await f.arrayBuffer());
    peaks = felbontas(buf.getChannelData(0), vaszon.width);
  });

  document.querySelector("#play").addEventListener("click", () => {
    ctx.resume();
    zene.play();
  });
  document.querySelector("#szunet").addEventListener("click", () => zene.pause());

  function frissit(most) {
    const dt = (most - utolso) / 1000;
    utolso = most;

    if (!zene.paused) forgas += 90 * dt;     // 90 fok másodpercenként
    lemez.style.transform = "rotate(" + forgas + "deg)";

    if (peaks.length && isFinite(zene.duration)) {
      rajzolHullam(zene.currentTime / zene.duration);
    }

    const adat = new Uint8Array(elemzo.fftSize);
    elemzo.getByteTimeDomainData(adat);
    let osszeg = 0;
    for (const v of adat) {
      const x = (v - 128) / 128;
      osszeg += x * x;
    }
    const rms = Math.sqrt(osszeg / adat.length);
    szint.style.width = Math.min(100, rms * 300) + "%";

    ido.textContent = formaz(zene.currentTime) + " / " + formaz(zene.duration);
    requestAnimationFrame(frissit);
  }
  requestAnimationFrame(frissit);
</script>
1. feladat: Ha a lemez forgása túl gyors, csökkentsd a 90-et 45-re. Ha a mozgás akadozik, nézd meg a Konzolt, és ellenőrizd, hogy nincs-e hibaüzenet.
2. feladat: A hullámformában a lejátszott rész színe legyen sötétebb lila, a hátralévő világos rózsaszín. Módosítsd a rajzolHullam függvényt.
3. feladat (bónusz): A hangerőmérő színe legyen zöld, ha a szint 0,3 alatt van, sárga 0,3 és 0,6 között, és piros 0,6 felett. A style.background változtatásával tudod megoldani.
Mi jön a 6. részben? A tempó: a BPM-elemzés, a SYNC gomb, és a hurok (loop). A pult legtöbb ritmikus részét ebben a részben építjük fel.
